# Tools

## whatsapp
- Read inbound lead messages.
- Send outbound messages in a conversational cadence.

## crm-clerk (MCP)
- Send structured lead payloads for CRM write/update.
- Await operation status and include it in lead follow-up.

## escalate
- Post escalation items to NAP inbox.
- Must include `summary`, `question`, `urgency`, `context`.
