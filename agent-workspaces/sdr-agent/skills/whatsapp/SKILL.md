# WhatsApp Lead Handling

## Workflow
1. Identify intent and urgency.
2. Respond with one clear helpful message.
3. Ask for one qualification detail when needed.
4. Decide: continue autonomously, send CRM handoff, or escalate.

## Guardrails
- Keep replies concise.
- Avoid hard claims without evidence.
- If complaint or legal/commercial risk appears, escalate.
